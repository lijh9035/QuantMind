# QuantMind 因子挖掘操作手册

适用范围：当前 QuantMind 因子挖掘（Alpha Research）页面，包括研究方向提交、因子库、单因子回测、样本外验证和训练特征物化。界面可能随版本变化；以页面实际提供的算法和预览结果为准。

## 1. 因子研究是什么

因子是一个可计算的变量，用来描述股票在某个时点的特征，例如动量、波动、成交量变化或财务质量。因子挖掘的目标是提出候选表达式，并用历史数据检查其与未来收益的关系。

因子 IC、因子回测收益和完整策略表现是不同层次：

1. **IC / Rank IC**：检查因子排序与未来收益是否有关联。
2. **分位组合 / 因子回测**：检查按因子分组后收益是否有差异，并观察换手和回撤。
3. **模型训练**：把已发布的特征输入模型，与目标标签一起拟合。
4. **策略回测**：把模型分数和交易规则组合成持仓与调仓。

一个因子被挖掘出来，不代表它在样本外有效，也不代表可直接交易。

## 2. 进入前检查

1. 登录 QuantMind，主导航点 **因子挖掘**。
2. 打开 **设置 → 模型与数据状态**，确认后端和数据状态可用。
3. 检查当前页面列出的算法。如果某种算法不可用，以页面提示为准。
4. RD-Agent 需要后端提供可用 LLM。设置页可以查看状态，但不是编辑 LLM 配置的入口。
5. AlphaSAGE 需要独立的 GPU 训练服务。若 GPU 或后端能力未就绪，先处理部署状态，不要反复点击提交。
6. 当前挖掘输入按 A 股日频流程工作；确认所选股票池的数据覆盖和日期范围。

系统可能根据资源设置限制并发研究任务；提交前预览里若出现环境、LLM、GPU、股票池或数据日期错误，先修正该前置条件。

## 3. 创建第一次挖掘任务

### 3.1 选择算法

| 算法 | 输入方式 | 需要什么 | 适合的起点 |
|---|---|---|---|
| RD-Agent | 研究假设文字、股票池、可选日期窗口 | LLM、数据与后端资源 | 用一句可检验的假设开始，观察生成的公式与实验轨迹 |
| 统计搜索 | 统计搜索配置、股票池、日期窗口 | 数据覆盖；日期区间必填 | 建立固定候选空间的量价基线 |
| AlphaSAGE | 股票池、预测周期、训练窗口、独立验证窗口、训练轮数和候选池容量 | GPU 训练服务 | 只在 GPU 服务显示可用时运行 |

算法选项由服务端返回；不要根据旧版介绍推断当前所有选项都已部署。

### 3.2 选择股票池和假设

1. 在 **股票池**选择一个范围已知的系统池或自定义池。
2. RD-Agent 的研究假设最好只写一个主要问题，说明变量、预测周期和观察范围。
3. 避免同时提出多个互不相关的假设，否则结果难以判断是哪一部分起作用。
4. 如果启用 **预设方向**，系统会采用“设置 → 挖掘方向”里配置的方向；关闭预设方向后再输入自定义假设。
5. 用于复现时，填写明确的挖掘日期和 OOS 样本外日期。RD-Agent 可以按后端默认窗口运行，但明示日期更方便之后比较。

研究假设模板：

> 在【股票池】中，检验【一个可观察的现象】与未来【N】个交易日收益之间的截面关系。挖掘区间为【日期】，样本外区间为【不重叠的日期】。请输出候选公式、信号方向、IC / Rank IC、跨期稳定性和换手后表现，并保留失败实验说明。

例如，问题应描述“验证某种量价变化与未来收益的关系”，而不是只写“找一个高收益因子”。

### 3.3 预览并提交

1. 点击 **预览并开始**，等待参数预览。
2. 检查算法、市场、股票池、日期、目标周期和算法要求。
3. 预览没有错误后确认提交。
4. 提交后可离开当前页；任务状态和详情保存在服务端任务记录中。

不同方法的日期规则不同：统计搜索要求挖掘窗口；AlphaSAGE 要求独立验证窗口；RD-Agent 可用服务端默认窗口。若页面阻止提交，优先按预览错误提示修正。

## 4. 查看演化结果和任务历史

1. 回到因子挖掘首页的实时演化台，查看排队、运行、停止、完成或失败状态。
2. 打开 **任务中心**，按任务 ID 查看日志、参数、候选表达式、Rank IC 和 RD-Agent 迭代轨迹。
3. 任务显示 **完成**只代表计算结束，不代表产生了因子，也不代表因子达到采用标准。
4. 若结果尚不可用，先确认任务完成，再刷新任务详情。
5. 需要中止时使用页面的 **停止** 操作；不要通过重启共享服务来取消个人任务。
6. 失败时保存错误消息和任务 ID，先检查数据覆盖、算法依赖、LLM/GPU 状态和所选窗口。

## 5. 在因子库检查候选因子

### 5.1 筛选和查看

1. 进入 **因子库**，选择 **本人挖掘**查看自己的研究结果。
2. **本人工厂**是另一类只读因子来源，不是本人本次提交的任务结果。
3. 搜索名称或因子 ID，打开详情检查公式、来源、股票池、已有回测和训练引用。
4. 同时看 IC、Rank IC、ICIR、Rank ICIR、收益分位、换手和跨期曲线。
5. 负 IC 可能代表因子方向与未来收益相反；先核实指标定义和公式方向，再决定是否反向使用。
6. 因子列表的质量等级只是筛选提示，不能代替样本外验证和交易成本检查。

### 5.2 独立回测和样本外验证

1. 在本人因子卡片点 **回测**，或打开首页的 **回测**入口。
2. 选择运行类型：
   - **回测**：在指定区间评估因子和分位组合；
   - **样本外验证**：在另一段时间检查已有假设是否延续。
3. 选择 A 股股票池并检查数据适配、日期和因子。
4. 提交后在 **任务中心**查看状态；完成后打开结果。
5. 至少检查平均 IC、Rank IC 中位数、换手后 Rank IC、年化收益、最大回撤、收益分位曲线和持仓比例变化。
6. 不要用挖掘区间本身的最好结果当作样本外结论。样本外时间窗应与挖掘窗口分开。

因子库的池正交和多样性证据需要先选择股票池。它帮助检查候选因子是否高度相似，并不会自动把因子组合成交易策略。

### 5.3 研究池、归档和恢复

- **加入本人因子池**：将通过初筛的本人因子加入个人研究池，方便后续池内评估。
- **池正交与多样性证据**：在选定股票池后查看多因子相似关系；先处理重复性，再考虑组合。
- **归档**：让因子退出当前活跃列表，保留历史回测、代码和训练引用，不会释放磁盘空间。
- **恢复**：恢复到在库列表后，若要继续研究，需要按页面要求重新加入本人因子池。
- **补码并评估**：针对缺少代码的历史记录尝试恢复代码并重新评估；结果要等任务完成后再确认。

## 6. 因子如何进入模型训练

挖掘任务当前不会默认自动把所有新因子变成训练输入。因子库中的 **物化训练特征**是单独的异步任务：

1. 对有代码且已经过初步验证的本人因子提交物化。
2. 在任务中心等待物化作业完成，检查结果中的字段或 generation 信息。
3. 到管理员的 **训练服务 → 数据发布**刷新字段发现。
4. 检查物化字段是否出现在对应市场/数据源，建立或调整映射并发布新的目录版本。
5. 回到模型训练页，确认新字段确实出现在可选特征目录中。

因子物化和训练目录发布是两个不同步骤；若字段没有出现在训练页，不能仅凭物化任务已完成就认为模型已经使用了它。因子物化只针对训练特征生成，不会自动创建模型或策略。

## 7. 常见问题

| 现象 | 排查顺序 |
|---|---|
| 提交按钮不可用 | 检查登录、算法能力列表、股票池、日期规则及预览错误 |
| RD-Agent 提示 LLM 错误 | 在设置页确认 LLM 可用状态；配置修改需由部署环境管理员处理 |
| AlphaSAGE 不可选或无法启动 | 检查 GPU 服务和算法能力列表；该流程不由 Ollama 聊天模型替代 |
| 任务完成但没有因子 | 读取任务日志、候选数量、代码和验证指标；完成状态不是通过认证 |
| 因子库看不到结果 | 检查同一账号、本人挖掘来源、任务是否完成，刷新后按任务 ID 查看 |
| 指标不错但策略不赚钱 | 看样本外、换手、成本、分位单调性和后续策略持仓规则 |
| 新因子不在训练页 | 检查物化作业、字段发现、训练目录映射和发布版本 |
