# QuantMind 量化研究操作总览

这份总览把三本专项手册串成一条实际研究流程，适用于本地 QuantMind：**因子挖掘 → 模型训练 → 策略回测与组合比较**。

## 阅读顺序

1. [因子挖掘操作手册](QuantMind_因子挖掘操作手册.md)：提出研究假设、查看候选因子、独立回测和样本外验证。
2. [模型训练与模型管理操作手册](QuantMind_模型训练与模型管理操作手册.md)：准备训练字段目录、配置标签和时间区间、运行训练并检查模型登记。
3. [策略回测与组合操作手册](QuantMind_策略回测与组合操作手册.md)：用模型信号和策略模板做组合回测、阅读结果、比较独立回测。
4. [模型算法和指标背景](QuantMind_模型训练完全指南.md)：需要理解不同算法或指标时再参考。

## 全流程图

~~~mermaid

  A[QuantDB 数据] --> B[因子挖掘]
  B --> C[因子库回测 / 样本外验证]
  C --> D[可选物化训练特征]
  A --> E[训练特征目录发现 / 映射 / 发布]

  E --> F[训练模型]
  F --> G[模型登记与就绪检查]
  G --> H[快速回测：模型信号 + 一个策略模板]
  H --> I[比较多次独立回测]
  G --> J[推理与模拟调仓]
~~~

## 三个必须分开的概念

- **因子挖掘**是在研究候选关系；任务完成不代表因子有效。
- **模型训练**使用已发布的特征目录和预测标签；训练页的自动因子筛选不等于独立因子挖掘。
- **策略回测**把模型分数变成股票选择和调仓规则；策略回测的高收益不替代样本外验证。

因子不会默认自动进入训练目录。若要把本人挖掘因子用于模型，需单独执行物化，并确认管理员训练目录里发现、映射和发布了对应字段。模型训练结束也不会自动构成策略；还要在回测中心选择模型和策略模板。

## 当前“策略组合”能力范围

当前回测中心的快速回测可选择 **一个模型 + 一个 Qlib 策略模板**生成一条组合回测；策略对比负责比较多条已完成回测，不会把策略按资金权重合并成新策略。推理中心可多选模型并行推理，但这也不是多策略组合。

因此，当前可以完整学习和操作的是**模型驱动的策略组合回测与结果比较**。若目标是将多个策略按固定权重合成一个账户组合，当前 UI / API 中没有发现可操作入口。

## 结合这套部署的起步顺序

此前核对 WSL 部署的快照（2026-11-20）显示：L1 因子数据有 2,638 个 Parquet 文件、数据库发现 120 个字段，但训练目录没有已发布版本和映射记录，用户模型表也为空。因此先完成训练目录发布和第一次模型训练；不需要手工下载预训练模型包来填充模型管理列表。

建议第一次演练：

1. 因子挖掘选一个股票池和单一研究假设，填写可复现的日期。
2. 在任务中心确认挖掘任务结束，并在因子库看公式和质量指标。
3. 对本人因子做回测或 OOS 验证；确定要用于训练后再单独物化并确认字段可用。
4. 管理员在训练数据发布页完成字段发现、草稿映射和目录发布。
5. 用 LightGBM 默认配置训练一条基线，确认模型注册状态为 ready。
6. 在回测中心使用该模型和一个 Top-K 模板运行回测。
7. 固定其他条件，只改变一个参数再跑一次，在策略对比页比较两条回测。

此顺序是教学练习，不是盈利承诺或生产准入标准。回测收益、挖掘任务完成状态、容器 Healthy 都不能代替实际产物与指标验收。

## 本地源码与运行部署

本手册按 Windows 主源码仓库的当前页面行为整理。Windows 源码目录和 WSL 运行部署是两个独立 checkout；若部署 UI 与手册不一致，先核对两边提交版本和实际页面，不要把未同步的源码行为当作运行实例已具备的功能。
